# n8n Pinterest Site

A cinematic website for the [@sinehypernova-0718/n8n-nodes-pinterest](https://www.npmjs.com/package/@sinehypernova-0718/n8n-nodes-pinterest) community node.

Built with Next.js 14, TypeScript, Tailwind CSS, and Turborepo.

## Features

- **Cinematic hero** with typography-derived atmospheric lighting
- **Advanced glassmorphism** with cursor-reactive spotlight
- **Reusable release journey** driven entirely by data
- **Complete documentation hub** covering installation, credentials, operations, and troubleshooting
- **Verified content** based on the actual published node repository
- **Full accessibility** with reduced-motion support

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 14.2 (App Router) |
| Language | TypeScript (strict) |
| Styling | Tailwind CSS 3.4 |
| Build | Turborepo + pnpm |
| Animation | Framer Motion + GSAP |
| Testing | Vitest + React Testing Library |
| Deploy | Vercel |

## Getting Started

```bash
# Install dependencies
pnpm install

# Development server
pnpm dev

# Type check
pnpm type-check

# Lint
pnpm lint

# Run tests
pnpm test

# Production build
pnpm build
